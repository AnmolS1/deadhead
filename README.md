# deadhead

A browser arcade taxi game. You drive, you pick people up, you drop them off.

The twist is the clock: it only runs while your cab is **empty**. Pick someone up and it
freezes. So the scarce resource isn't time, it's _deadhead_ — the industry term for driving
with nobody in the back.

**Status: nothing to play yet.** `deadhead` is a working codename. The name, the art
direction, and the release plan are all still open.
